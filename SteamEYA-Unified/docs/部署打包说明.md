# 部署与打包说明（客户端 / 服务端划分）

## 一、先分清：谁跑在哪

| 组成 | 源码位置 | 运行位置 | 作用 |
|---|---|---|---|
| **统一后端网关（在线）** | `server/` | **云服务器（Linux）** | 统一账号、Steam 分发、云游戏 Cookie、聊天室 HTTP+WS、云存档；并托管聊天 Web 前端与上传文件 |
| **聊天 Web 前端** | `web/` | 由网关托管（同一份，无需单独部署） | WebView2 / 浏览器打开的聊天界面 |
| **桌面客户端** | `client/`（WinUI3，C#） | **用户 Windows 电脑** | 登录页 + 主界面（Steam 上号 / 云游戏上号 / 聊天室 / 云存档…） |
| **云游戏引擎** | `engine/` | **用户 Windows 电脑**（本机服务） | Selenium 抓/注入 Cookie；需本机有 Chrome/Edge |
| **离线本机网关** | `server/`（同一套代码，打包成 exe） | **用户 Windows 电脑**（离线时） | 无网络时在 127.0.0.1 跑同一套后端，提供局域网聊天与本地数据 |

结论一句话：
- **纯服务端** = `server/`（部署到云服务器）。
- **纯客户端** = `client/`（Windows 桌面程序）。
- **要随客户端一起打包** = `web/` + `server` 打成的 `steameya-gateway.exe`（离线用）+ `engine` 打成的 `steameya-engine.exe`（云游戏用）。

## 二、服务端：怎么部署

**服务器：`server/`（Linux 云服务器，示例 47.104.210.199）**

```bash
# 1) 拷贝 server/ 到服务器后
cd server
pip install -r requirements.txt
# 2) 生成密钥（生产务必设置）
export EYA_SECRET_KEY="换成一段随机字符串"
# 3) 启动（常驻见下方）
python run_server.py --port 8897
```

- 首次启动自动建库并创建管理员 **admin / admin123**，请尽快在后台改密码。
- 健康检查：`GET http://<服务器IP>:8897/health`
- 聊天前端：浏览器打开 `http://<服务器IP>:8897/` 即是聊天室。
- 管理后台（需管理员账号登录）：
  - 聊天管理：`http://<服务器IP>:8897/admin.html`（用户/私聊记录/邀请码/PushPlus 推送配置/面板预设）
  - Steam 账号管理：`http://<服务器IP>:8897/admin-steam.html`（账号列表、批量导入、编辑/删除、操作日志）
  - 云游戏账号管理：`http://<服务器IP>:8897/admin-cloud.html`（Cookie 记录、有效性检测、删除、上号日志）
  - 三个页面顶部互相跳转；默认管理员 `admin / admin123`。
- 常驻运行（任选）：
  - `nohup python run_server.py --port 8897 > server.log 2>&1 &`
  - systemd service
  - 宝塔面板「Python 项目管理器」
- 生产建议：前面挂 **Nginx + HTTPS**（客户端里把 `SessionState.OnlineBaseUrl` 改成你的 https 域名），开放 8897 端口，限制 `/uploads` 访问权限。

**服务端包含的文件：**
```
server/
  app/…            （全部后端逻辑，含 routers/admin.py 管理后台接口、push.py 推送）
  requirements.txt
  run_server.py    ← 在线启动入口
  gateway_main.py  （打包入口，在线/离线共用）
  web 由仓库根目录 web/ 提供（部署时把 web/ 放到 server 同级，或用 EYA_WEB_DIR 指定）
```

**管理后台接口（前缀）：**
- 聊天管理：`/api/admin/*`（用户、封禁、新建用户、重置密码、改昵称、私聊记录、邀请码、PushPlus 推送配置、面板预设）
- Steam 账号管理：`/api/steam/admin/*`（账号列表/批量导入/编辑/删除、用户、日志、统计、设置）
- 云游戏账号管理：`/api/cloud/admin/*`（账号列表、统计、有效性检测、删除、上号日志）

> 说明：聊天 Web 前端目录 `web/` 需与网关一起部署。网关默认在 `server 同级` 找 `web/`；也可用环境变量 `EYA_WEB_DIR` 指定。

## 三、客户端：怎么打包

### 第 1 步：构建「云游戏引擎」exe（Windows）
```
双击运行  engine\build_engine.bat
产物：      engine\dist\steameya-engine.exe
```
需已装 Python 3 与 pip；该脚本会自动装 selenium/pyinstaller。

### 第 2 步：构建「离线本机网关」exe（Windows）
```
双击运行  server\build_gateway.bat
产物：      server\dist\steameya-gateway.exe
```

### 第 3 步：构建 WinUI 客户端（Windows + .NET 10 SDK + VS C++ 工具链）
```powershell
dotnet publish client\SteamEyaWinUI\SteamEyaWinUI.csproj -c Release -r win-x64 -p:Platform=x64
# 产物在 client\SteamEyaWinUI\bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\
```

### 第 4 步：按下面的目录结构组装（关键）
```
<安装目录>\
├─ SteamEyaWinUI.exe                ← 客户端主程序（含依赖 dll / Assets / Languages）
├─ gateway\steameya-gateway.exe     ← 离线本机网关（第 2 步产物）
├─ engine\steameya-engine.exe       ← 云游戏引擎（第 1 步产物）
└─ web\                             ← 聊天前端（把仓库根目录 web/ 整个拷进来）
     ├─ index.html
     ├─ css\  js\
     ├─ admin.html                  ← 聊天管理后台
     ├─ admin-steam.html            ← Steam 账号管理后台
     └─ admin-cloud.html            ← 云游戏账号管理后台
```
客户端会按固定位置自动查找它们：
- 离线网关：`<AppDir>\gateway\steameya-gateway.exe`（见 `GatewayLauncher`）
- 云游戏引擎：`<AppDir>\engine\steameya-engine.exe`（见 `EngineLauncher`）
- 聊天前端：`<AppDir>\web`（自动通过 `EYA_WEB_DIR` 传给本机网关）

### 第 5 步：打成安装包（Inno Setup）
用仓库自带的脚本 `client\build\installer\SteamEYA.iss` 生成 `SteamEYA-<版本>-win-x64-setup.exe`，
把上面 `gateway\`、`engine\`、`web\` 一并加入安装文件列表即可（安装后结构同上）。

### 运行环境要求（用户电脑）
- Windows 10 1809（Build 17763）及以上
- **WebView2 运行时**（Win11 自带；Win10 可能需安装）
- 云游戏功能需本机已装 **Chrome 或 Edge**

## 四、按需最小组合

| 使用场景 | 需要部署 / 携带 |
|---|---|
| 仅在线聊天、Steam 上号 | 服务端 `server/` + 客户端 |
| 云游戏上号 | 客户端额外带 `engine\steameya-engine.exe` + 本机浏览器 |
| 无网络（局域网聊天 + 离线记录同步） | 客户端额外带 `gateway\steameya-gateway.exe` + `web\` |

## 五、一句话清单

- **服务端（上服务器）**：`server/`（+ `web/` 放同级）。
- **客户端（发给用户）**：`client/` 编译产物，外加
  `engine\dist\steameya-engine.exe`、`server\dist\steameya-gateway.exe`、`web\`。
- **文档**：`docs/方案设计.md`、本文件、`README.md`。
